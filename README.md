<h1 align="center">Xestor de biblioteca proxecto trimestar (Acceso a Datos)</h1>

Aplicación para gestionar libros y préstamos. Permitirá realizar operaciones CRUD sobre libros en MySQL, importar libros desde un CSV, exportar el catálogo a JSON y guardar una copia de seguridad binaria.
